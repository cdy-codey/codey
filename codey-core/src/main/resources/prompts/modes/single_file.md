## Single File Mode

当前为单表模式：工作目录内所有文件内容已在系统提示词中提供。
你的主任务始终依据这些已提供的完整文件内容进行。

### 核心规则

- **不需要读文件工具**：read_file 和 search_content 工具未暴露给你，你也无需调用它们。所有文件内容已在上下文中，直接使用即可。
- **文件内容会每轮自动刷新**：如果你写入了新文件或修改了现有文件，下一轮对话时系统会自动将最新内容刷新到你的上下文中。因此，写完文件后无需再用读工具验证——下一轮自然能看到最新内容。
- **优先基于已有内容回答**：不要因为"没读过文件"而拒绝回答，文件内容已经在你的上下文里了。
- **只有在极少数情况下（如需要读取本工作目录之外的系统路径文件）才考虑使用其他方式获取文件内容**，正常场景下完全不需要。

### 工作习惯

- 直接引用系统提示词中已有文件的内容进行推理和修改。
- 修改文件后直接描述改动，无需再调用读取工具验证。
- 如遇到文件内容截断标记（`<!-- 文件过长，已截断至 ... -->`），说明该文件过大未完全加载，可通过用户补充或细分任务来处理。

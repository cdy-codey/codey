# 上下文摘要业务图

本文只说明“上下文摘要”这条业务链路，不展开代码实现细节。

## 业务图

```mermaid
flowchart TD
    A[开始对话] --> B[组装当前上下文]
    B --> C{上下文是否超过 800k?}

    C -- 是 --> D[提示用户重新开启会话]
    C -- 否 --> E{是否达到摘要触发条件?}

    E -- 是 --> F[先生成上下文摘要]
    F --> G[用新摘要替换旧摘要]
    G --> H[删除其他旧历史<br/>仅保留必要上下文]
    H --> I[继续业务请求]

    E -- 否 --> I[继续业务请求]

    I --> J{本轮是否调用工具?}
    J -- 是 --> K[执行工具并进入下一轮]
    K --> B

    J -- 否 --> L{本轮是否结束?}
    L -- 否 --> B
    L -- 是 --> M[再生成一次最终摘要]
    M --> N[返回结果]
```

## 业务规则

- 中途如果上下文变长了，先摘要再继续。
- 首次达到 `50k` 字符时生成摘要，之后每新增 `50k` 字符再生成一次。
- 本轮 loop 结束时，再额外生成一次最终摘要。
- 如果上下文达到 `800k`，不再继续执行，直接提示用户重新开启会话。
- 业务请求最终会同时带上摘要和最近必要上下文，不会只剩摘要。
